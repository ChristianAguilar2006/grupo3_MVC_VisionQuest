# ExamenProgra

VisionQuest: registro de sintezoides y recuerdos con ASP.NET MVC 5, Entity Framework 6 y SQL Server LocalDB.

Para ejecutar:

1. Abrir `VisionQuest.slnx` en Visual Studio y restaurar los paquetes NuGet.
2. Ejecutar `Update-Database` en la Consola del Administrador de paquetes.
3. Iniciar el proyecto con F5.
